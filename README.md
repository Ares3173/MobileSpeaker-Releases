# Mobile Speaker

Play your computer's audio through the Mobile Speaker app on your iPhone. The Windows and Mac computer companions are free.

## Get the Computer App

**Windows:** [Download MobileSpeaker.exe (version 0.1.3, Windows x64)](https://github.com/Ares3173/MobileSpeaker-Releases/releases/download/windows-v0.1.3/MobileSpeaker.exe)

Open the downloaded EXE. No installer or separate .NET download is needed. You only need the EXE, not the update JSON or signature files.

**Mac:** Coming soon. A verified Mac download will be linked here when it is published.

## Start Listening

1. Open Mobile Speaker on your computer and iPhone.
2. Choose **Wi-Fi** or **USB**, then click **Start sharing** on the computer.
3. Choose the matching connection method on iPhone and scan the computer's QR code. Play audio on your computer.

For **Wi-Fi**, connect both devices to the same network and allow Local Network access on iPhone. Hotel and public Wi-Fi may block connections between devices; use USB if that happens. Wi-Fi audio and pairing are not encrypted, so use USB for private audio on shared networks.

For **USB**, connect your iPhone with a data-capable cable, unlock it, and accept **Trust This Computer** if prompted. Windows needs Apple's device support. If it is missing, open **USB setup** in Mobile Speaker, or install [Apple Devices from the Microsoft Store](https://apps.microsoft.com/detail/9np83lwlpz9k). See [Apple's installation guide](https://support.apple.com/guide/devices-windows/install-the-apple-devices-app-mchl5ded2763/windows). USB does not require a shared Wi-Fi connection.

## Updates and Download Safety

While sharing is stopped, open **Settings > Check for updates**. Mobile Speaker verifies signed update metadata and the downloaded app before installing an update.

This Windows release does not have a publicly trusted publisher certificate, so Windows may show an unknown-publisher or SmartScreen warning. Download only from this repository. Do not disable Windows security protections.
